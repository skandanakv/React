### 📦 What is Bundling?

Bundling is the process of combining multiple files (JavaScript, CSS, images, etc.) into optimized output files so that the browser can load the application faster and efficiently.

Modern bundlers automate this process and improve performance and developer experience.

---

## 🔥 Features of Modern Bundlers

### 1️⃣ Development Build (Dev Build)

* Provides fast builds during development.
* Includes debugging tools and readable code.
* Helps in quick iteration and testing.

---

### 2️⃣ Local Development Server

* Starts a local server for running applications.
* Automatically reloads the browser when changes are made.

Example:

```
npx parcel index.html
```

---

### 3️⃣ Hot Module Replacement (HMR)

* Updates only the changed module.
* Avoids full page refresh.
* Improves development speed.

---

### 4️⃣ Tree Shaking

* Removes unused or dead code.
* Reduces bundle size.
* Improves application performance.

---

### 5️⃣ Error Handling

* Detects syntax and runtime errors.
* Displays clear error messages during development.

---

### 6️⃣ Caching

* Stores build results.
* Avoids rebuilding unchanged files.
* Speeds up build process.

---

### 7️⃣ File Watching Algorithm

* Watches project files continuously.
* Rebuilds automatically when files change.

---

### 8️⃣ Minification

* Removes spaces, comments, and extra formatting.
* Produces smaller optimized code.

---

### 9️⃣ Compression

* Compresses files using techniques like Gzip or Brotli.
* Improves loading speed.

---

### 🔟 Differential Bundling

* Generates different bundles for modern and older browsers.
* Ensures compatibility and performance.

---

## 🎯 Why Bundlers Are Important

* Faster website performance
* Optimized and smaller bundle size
* Better developer experience
* Improved scalability
* Support for modern JavaScript
